# Steam Generation Process: Nonlinear Dynamics & Statistical Signal Analysis

Research project focused on analyzing the nonlinear and dynamically changing behavior of a thermal power plant steam-generation process using statistical signal analysis, nonlinear dynamics, and machine learning.

## Research Areas

- Nonlinear dynamical systems
- Time-series analysis
- Statistical signal analysis
- Process modeling
- Feature selection
- Machine learning
- Steam-temperature prediction

## Research Methods

- Hurst Exponent Analysis
- Time-Lag Analysis
- State-Space Analysis
- OLS Regression
- mRMR
- AIC
- Multiple Linear Regression
- Artificial Neural Networks
- Sliding-Window Modeling
